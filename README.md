# YT Cut Bot 🎬

Bot Telegram untuk download potongan video YouTube.

## Cara Pakai
Kirim pesan ke bot dengan format:
```
<link YouTube> <menit mulai> <menit selesai>
```

Contoh:
```
https://youtube.com/watch?v=xxx 6:00 7:00
```

## Deploy ke Railway
1. Upload semua file ini ke GitHub
2. Buka railway.app → New Project → Deploy from GitHub
3. Tambahkan environment variable: `BOT_TOKEN` = token bot kamu
4. Deploy!
